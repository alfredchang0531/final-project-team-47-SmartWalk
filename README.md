# final-project-team-47-SmartWalk
WalkSmart is a web-based map application that helps users find useful places within a realistic walking time from a chosen starting point. Instead of only measuring straight-line distance, the system uses routing data to estimate real walking time and displays the results on an interactive map.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000` and:

1. Enter a start location in natural language.
2. Choose a category and walking-time limit.
3. View ranked places, route-aware walking details, map visualization, and WalkSmart Convenience Score.
